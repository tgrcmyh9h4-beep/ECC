# Adjectives: Describing Things

## What is an adjective?
An adjective describes a noun. It tells us **what kind**, **what colour**, **how big**, **how many** and more.
- a **red** car, a **tall** man, **cold** water, an **interesting** book

## Where do adjectives go?
1. **Before a noun**: a **big** house, **delicious** food
2. **After be, look, seem, feel, taste, smell, sound, become, get**: The house is **big**. You look **tired**. This soup tastes **good**.
! a house big => a **big** house
! the girl beautiful => the **beautiful** girl
### Adjectives never take -s
! They are goods students. => They are **good** students.
! I have two reds cars. => I have two **red** cars.

## Order of adjectives
When you use two or more adjectives, there is a usual order:
| Opinion | Size | Age | Shape | Colour | Origin | Material | Purpose | Noun |
| beautiful | big | old | round | brown | Italian | wooden | dining | table |
| lovely | small | new | – | white | Indian | cotton | – | shirt |
- a **lovely little old** house
- a **big black leather** bag
- **beautiful long black** hair
- a **new red sports** car
> **Tip:** In real life we rarely use more than two or three adjectives together. Remember: **opinion** first, then **facts** (size, age, colour...).

## -ed and -ing adjectives
This is a very common mistake!
- **-ed** adjectives describe **how a person feels**: I'm **bored**. She is **interested** in art. We were **tired**.
- **-ing** adjectives describe **the thing that causes the feeling**: The film is **boring**. Art is **interesting**. It was a **tiring** day.
| -ed (feeling) | -ing (cause) |
| bored | boring |
| interested | interesting |
| excited | exciting |
| tired | tiring |
| surprised | surprising |
| confused | confusing |
| embarrassed | embarrassing |
| frightened | frightening |
| worried | worrying |
| amazed | amazing |
| annoyed | annoying |
| disappointed | disappointing |
| relaxed | relaxing |
| satisfied | satisfying |
! I am very boring in this class. => I am very **bored** in this class. ("I am boring" means you make other people bored!)
! The news was very shocked. => The news was very **shocking**.

## Comparatives and superlatives
We use **comparatives** to compare two things: "Delhi is **bigger than** Jaipur."
We use **superlatives** to compare one thing with a whole group: "Mumbai is **the biggest** city in India."
### The rules
| Adjective | Comparative | Superlative |
| One syllable: add -er / -est | tall → taller | the tallest |
| | cheap → cheaper | the cheapest |
| | old → older | the oldest |
| Ends in -e: add -r / -st | nice → nicer | the nicest |
| | large → larger | the largest |
| One vowel + one consonant: double the consonant | big → bigger | the biggest |
| | hot → hotter | the hottest |
| | thin → thinner | the thinnest |
| Ends in -y: y → -ier / -iest | happy → happier | the happiest |
| | easy → easier | the easiest |
| | busy → busier | the busiest |
| Two or more syllables: more / most | beautiful → more beautiful | the most beautiful |
| | expensive → more expensive | the most expensive |
| | interesting → more interesting | the most interesting |
### Irregular forms – very common!
| Adjective | Comparative | Superlative |
| good | better | the best |
| bad | worse | the worst |
| far | farther / further | the farthest / furthest |
| little (amount) | less | the least |
| much / many | more | the most |
### Examples
- My brother is **taller than** me.
- This phone is **more expensive than** that one.
- Today is **hotter than** yesterday.
- She is **the best** singer in our school.
- That was **the worst** day of my life.
- Gold is **heavier than** silver.
- This is **the most beautiful** place I have ever seen.
! He is more tall than me. => He is **taller** than me.
! She is the most good. => She is **the best**.
! This is more better. => This is **better**. (never "more better")
! He is taller then me. => He is taller **than** me. ("then" = after that)

## Other ways to compare
### as ... as (the same)
- She is **as tall as** her mother. (same height)
- This book is **not as interesting as** the film. (the film is more interesting)
- Come **as soon as** possible.
### less ... than
- This hotel is **less expensive than** that one.
### much / a lot / a bit / slightly + comparative
- He is **much older** than his wife.
- Can you speak **a bit slower**, please?
- This one is **a lot cheaper**.
### the ... the ...
- **The more** you practise, **the better** you speak.
- **The sooner, the better.**
### getting + comparative + and + comparative
- It's getting **colder and colder**.
- Your English is getting **better and better**!

## Too and enough
- **too** + adjective = more than is good: "This tea is **too hot** to drink." "He is **too young** to drive."
- adjective + **enough** = sufficient: "She is **old enough** to vote." "This room isn't **big enough**."
- **enough** + noun: "We have **enough money**." "There isn't **enough time**."
! He is enough old. => He is old **enough**.
! It is too much hot. => It is **too** hot. / It is **very** hot.
> **Tip:** "Too" usually has a negative feeling. "It's very beautiful" (good). "It's too beautiful" sounds strange. Say "It's so beautiful!"

## Very, really, so, quite, extremely
| Word | Strength | Example |
| a bit / a little | weak | I'm a bit tired. |
| quite / fairly / pretty | medium | The test was quite easy. |
| very / really | strong | She's very kind. |
| so | strong (emotional) | You're so funny! |
| extremely / incredibly | very strong | It was extremely cold. |
### Strong adjectives
Some adjectives are already very strong. Use **absolutely** or **really** with them, not "very":
| Normal | Strong |
| good | excellent, fantastic, amazing, brilliant |
| bad | terrible, awful, horrible |
| big | huge, enormous, massive |
| small | tiny |
| tired | exhausted |
| hungry | starving |
| cold | freezing |
| hot | boiling |
| angry | furious |
| happy | delighted, thrilled |
| scared | terrified |
| surprised | amazed, astonished |
| dirty | filthy |
| clean | spotless |
| interesting | fascinating |
| funny | hilarious |
- I'm **absolutely starving**! (not "very starving")
- The film was **really hilarious**.

# Adverbs: How, When, Where, How Often

## What is an adverb?
An adverb gives more information about a **verb** (how/when/where something happens), an **adjective** or another **adverb**.
- She sings **beautifully**. (how?)
- I'll call you **tomorrow**. (when?)
- Come **here**. (where?)
- He is **always** late. (how often?)
- It's **very** cold. (how much?)

## Making adverbs of manner (-ly)
Most adverbs of manner = adjective + **-ly**.
| Adjective | Adverb |
| slow | slowly |
| quick | quickly |
| careful | carefully |
| quiet | quietly |
| bad | badly |
| easy | easily (y → ily) |
| happy | happily |
| angry | angrily |
| gentle | gently (le → ly) |
| terrible | terribly |
| automatic | automatically (ic → ically) |
### Irregular adverbs
| Adjective | Adverb |
| good | **well** |
| fast | **fast** |
| hard | **hard** |
| early | **early** |
| late | **late** |
| straight | **straight** |
- She is a **good** singer. → She sings **well**.
- He is a **fast** runner. → He runs **fast**.
- She works **hard**. ("hardly" means "almost not": "I can **hardly** hear you.")
- He arrived **late**. ("lately" means "recently": "Have you seen him **lately**?")
! He speaks English very good. => He speaks English very **well**.
! Drive careful! => Drive **carefully**!
! She works very hardly. => She works very **hard**.
### "Well" as an adjective
"Well" can also mean "healthy": "I don't feel **well**." "Get **well** soon!"
### Some -ly words are adjectives
friendly, lovely, lonely, ugly, silly, elderly, likely are **adjectives**: "She is very **friendly**." To make an adverb: "She spoke **in a friendly way**."

## Adverbs of frequency (how often?)
| 100% | | | | | 0% |
| always | usually | often | sometimes | rarely / seldom | never |
Other: normally, generally, frequently, occasionally, hardly ever
### Position
- **Before** the main verb: I **always** drink tea in the morning. She **never** eats meat.
- **After** the verb "be": He is **always** late. They are **often** busy.
- After the first auxiliary: I have **never** been to Japan. You can **always** call me.
! I go always to the gym. => I **always go** to the gym.
! She never is late. => She is **never** late.
### "How often" expressions (usually at the end)
every day, every week, once a week, twice a month, three times a year, on Mondays, at weekends, from time to time, now and then
- I visit my parents **twice a month**.
- We go to the cinema **once a week**.

## Adverbs of time and place
- **Time**: now, today, tomorrow, yesterday, soon, later, already, yet, still, just, recently, before, ago, tonight
- **Place**: here, there, everywhere, somewhere, nowhere, inside, outside, upstairs, downstairs, abroad, nearby, away, home
Order at the end of the sentence: **Manner + Place + Time**
- She sang **beautifully** **at the concert** **last night**.
- I worked **hard** **at the office** **yesterday**.

## Still, yet, already, just
| Word | Meaning | Example |
| already | sooner than expected | I've **already** finished. |
| yet | until now (negatives, questions) | Have you eaten **yet**? I haven't finished **yet**. |
| still | continuing, not finished | She's **still** sleeping. I **still** don't understand. |
| just | a very short time ago | He's **just** left. |
EX: Adjective or adverb?
1. She is a (careful / carefully) driver. || careful
2. She drives (careful / carefully). || carefully
3. He speaks English (good / well). || well
4. The test was (easy / easily). || easy
5. I can do this (easy / easily). || easily
6. They work very (hard / hardly). || hard
7. Please speak (quiet / quietly). || quietly
8. You look (sad / sadly). || sad (after "look", use an adjective)
EX: Put the adverb in the correct place
1. I drink coffee. (never) || I never drink coffee.
2. She is happy. (always) || She is always happy.
3. They play tennis. (sometimes) || They sometimes play tennis.
4. We have been to Goa. (never) || We have never been to Goa.
5. He is late for work. (often) || He is often late for work.

# Prepositions of Time, Place and Movement

## Prepositions of time: AT, ON, IN
| AT (exact time) | ON (days and dates) | IN (longer periods) |
| at 5 o'clock | on Monday | in the morning |
| at 7:30 | on Sunday morning | in the afternoon / evening |
| at noon / midnight | on 15th August | in July |
| at night | on my birthday | in summer / winter |
| at the weekend (UK) | on the weekend (US) | in 2026 |
| at Christmas / Diwali (the period) | on Christmas Day | in the 1990s |
| at the moment | on New Year's Eve | in the 21st century |
| at lunchtime | on weekdays | in two weeks (future) |
> **Tip:** Think of a triangle: **IN** is for big periods (years, months, seasons), **ON** for days, **AT** for exact times.
! I was born in 5th May. => I was born **on** 5th May.
! See you on 6 o'clock. => See you **at** 6 o'clock.
! I study at the morning. => I study **in** the morning.
! We met in night. => We met **at** night.
### No preposition before: this, next, last, every, tomorrow, yesterday
- I'll see you **next week**. (not "in next week")
- We met **last Friday**. (not "on last Friday")
- I go swimming **every day**.
### Other time prepositions
| Preposition | Example |
| for (length of time) | I lived there **for** five years. |
| since (start point) | I've lived here **since** 2019. |
| during (within a period) | He slept **during** the film. |
| from ... to / until | The shop is open **from** 9 **to** 6. |
| until / till (up to a time) | Wait **until** I come back. |
| by (not later than) | Please finish the work **by** Friday. |
| before / after | Wash your hands **before** eating. |
| ago (back from now) | I came here two years **ago**. |
| within | Reply **within** 24 hours. |

## Prepositions of place: AT, ON, IN
| AT (a point) | ON (a surface / line) | IN (inside / an area) |
| at the bus stop | on the table | in the box |
| at the door | on the wall | in the room |
| at home / at work / at school | on the floor | in the car / in a taxi |
| at the station / airport | on the bus / train / plane | in the garden |
| at the top / bottom | on the first floor | in Delhi / in India |
| at the corner | on the left / right | in the picture |
| at a party / concert | on the screen / page | in bed / in hospital |
| at 25 MG Road (full address) | on MG Road (street) | in the newspaper |
! I am in home. => I am **at** home.
! The picture is in the wall. => The picture is **on** the wall.
! She is on the car. => She is **in** the car. (but **on** the bus / train)
### Other place prepositions
| Preposition | Example |
| under / below | The cat is **under** the bed. |
| above / over | There's a clock **above** the door. |
| next to / beside | The bank is **next to** the post office. |
| between | I sat **between** Ali and Sara. |
| among | a house **among** the trees |
| in front of | There's a car **in front of** my house. |
| behind | The garden is **behind** the house. |
| opposite | The school is **opposite** the park. |
| near / close to | I live **near** the station. |
| inside / outside | Wait **outside**, please. |
| around | We sat **around** the table. |
| across from (US) | The café is **across from** the bank. |
! beside of the house => **beside** the house
! next the bank => next **to** the bank

## Prepositions of movement
| Preposition | Example |
| to | I go **to** work by bus. |
| into | She walked **into** the room. |
| out of | He ran **out of** the house. |
| onto | The cat jumped **onto** the table. |
| off | Get **off** the bus at the next stop. |
| up / down | Walk **up** the stairs. / Come **down**! |
| along | We walked **along** the beach. |
| across | Swim **across** the river. |
| through | The train went **through** the tunnel. |
| past | Go **past** the hospital and turn left. |
| over | Jump **over** the wall. |
| around / round | Walk **around** the lake. |
| towards | He ran **towards** me. |
| from | I came **from** the office. |
! I go to home. => I go home. (no "to" with home)
! We arrived to the airport. => We arrived **at** the airport. (arrive **at** a place, arrive **in** a city/country)
! I'm going to abroad. => I'm going abroad.

## Transport: by, on, in
- **by** + transport (no article): by car, by bus, by train, by plane, by bike, by taxi
- **on foot** (walking)
- **on** the bus / train / plane / bike / boat (big transport, you can stand)
- **in** a car / taxi / small boat (you sit and cannot walk around)
! I came by my car. => I came **in** my car. / I came **by car**.
